# 📁 Dosya Yönetim Portalı - Vize Projesi

Bu proje, **Akdeniz Üniversitesi Bilgisayar Programcılığı** bölümü Web Tabanlı Programlama dersi vize ödevi kapsamında geliştirilmiştir.

## 🚀 Canlı Demo
Proje canlı sunucu ortamında çalışmaktadır:
👉 **[http://hamzakyol-001-site1.htempurl.com](http://hamzakyol-001-site1.htempurl.com)**

## 🛠️ Kullanılan Teknolojiler
- **Backend:** ASP.NET Core MVC (.NET 8/9)
- **Database:** MSSQL (Entity Framework Core - Code First)
- **Deployment:** SmarterASP.NET (IIS Web Deploy)
- **Frontend:** Bootstrap, Razor Views
